# GESCAR · Mantenimiento de vehículos

PWA para gestionar el mantenimiento preventivo, correctivo y predictivo de vehículos (Mercedes CLK 270 CDI W209 y Citroën Xsara Picasso 1.6 HDi), con historiales separados por vehículo.

Instalar en iPhone: abrir la web en Safari → Compartir → «Añadir a pantalla de inicio».

Los datos se guardan solo en el dispositivo (IndexedDB). Haz copias de seguridad desde «Más → Copias de seguridad».
